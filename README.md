## Java: criando sua primeira API e conectando ao front

Projeto desenvolvido no terceiro curso da formação Avançando com Java da Alura

### 🔨 Objetivos do projeto

- Atualizar o projeto ScreenMatch, criado inicialmente com linha de comando, para se transformar em
  uma API REST;
- Entender a estrutura MVC no desenvolvimento de aplicações Web;
- Criar e mapear rotas utilizando como anotações da Primavera;
- Utilizar boas práticas e entrar o conceito de DTO (Objeto de Transferência de Dados);
- Conectar dados dispensados pelo back-end à uma aplicação front-end, dispensada nesse link
- Tratar erros de CORS na disponibilização de dados;
- Fornecer uma experiência fullstack, demonstrar o fluxo ponta a ponta da aplicação.
